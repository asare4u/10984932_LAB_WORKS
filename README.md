## Setup and Usage

To run the scripts in this repository, you'll need to have the following libraries installed:
* `opencv-python`
* `matplotlib`

You can install them using pip:
```bash
pip install opencv-python matplotlib
```

To run a specific task's script, navigate to its directory in your terminal and execute the Python file. For example:
```bash
cd Task1
python task1_script.py
```
